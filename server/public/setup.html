1. Ton compte MyOpel

Les identifiants de l'appli MyOpel. Ils sont transmis à psacc sur ta VM, nulle part ailleurs.

La connexion peut prendre jusqu'à 2 minutes.

1 bis. Récupérer le code de connexion

Stellantis demande une étape manuelle, à faire sur un ordinateur (Firefox ou Chrome) :

  1. Clique sur le bouton ci-dessous : la page MyOpel s'ouvre dans un nouvel onglet.
  2. Dans cet onglet, avant de te connecter, appuie sur F12 → onglet Réseau → ⚙️ → coche « Conserver les journaux ».
  3. Connecte-toi. La page reste blanche ou propose d'ouvrir une appli : clique sur Annuler.
  4. Dans le panneau Réseau, fais Ctrl+Maj+F et cherche code= : copie l'adresse qui commence par mym…:// (ou seulement la valeur après code=).
  5. Colle-la ci-dessous rapidement : le code expire en quelques minutes.
Ouvrir la page de connexion MyOpel

2. Autoriser les commandes à distance

Pour démarrer ou arrêter la charge et le préchauffage, Stellantis demande une validation par SMS et ton code PIN MyOpel (les 4 chiffres que tu tapes dans l'appli pour une commande à distance).

Évite de redemander plusieurs SMS d'affilée : Stellantis limite les envois.
